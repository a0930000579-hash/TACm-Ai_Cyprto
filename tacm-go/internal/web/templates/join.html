💻 一鍵加入指令

{% if network == "testnet" %} 
git clone {{ repo }}.git
cd TACm-Ai_Cyprto/tacm-go
go build -o tacweb ./cmd/web
go build -o tacnode ./cmd/node
./tacweb -network testnet -web-port 8080 -rpc-port 8080 -data-dir ./data-testnet -block-time 2 -difficulty 1 -p2p -p2p-url http://<你的公網IP>:8080 -p2p-seed <testnet錨點URL> -p2p-follower

把 <你的公網IP> 與 <testnet錨點URL> 換成實際值後逐行執行。testnet 使用獨立鏈 ID tacm-testnet-1 與獨立資料目錄，與主網完全分離，可放心試跑。

{% else %} 
git clone {{ repo }}.git
cd TACm-Ai_Cyprto/tacm-go
go build -o tacweb ./cmd/web
go build -o tacnode ./cmd/node
./tacweb -web-port 8080 -rpc-port 8080 -data-dir ./data -block-time 2 -difficulty 3 -p2p -p2p-url http://<你的公網IP>:8080 -p2p-seed http://2.28.201.174:8080 -p2p-follower

把 <你的公網IP> 換成你自己的 IP 後逐行執行。啟動後以 -p2p-seed 連上錨點完成握手，即開始同步主網。
